সবার আগে: ZIP-এর সব ফাইল Extract করো। তারপর NEXUS folder-এর NEXUS.exe ডাবল-ক্লিক করো। আলাদা Python installation, pip command, API key বা .env configuration লাগবে না।
চালু করোফাইল তালিকাপ্রথম ডাউনলোডভয়েসকাজ ও মেমোরিপুরোনো versionসমস্যা সমাধানপরীক্ষার ফল

১. প্রথমবার চালু করার নিয়ম

  1. ZIP Extract করো। Windows-এর Extract All ব্যবহার করো। ZIP preview-এর ভেতর থেকে executable চালিও না। একটি সাধারণ local folder বেছে নাও—যেমন D:\Apps\NEXUS। NEXUS.exe-কে runtime folder থেকে আলাদা করলে চলবে না।
  2. NEXUS.exe ডাবল-ক্লিক করো। এটি bundled Python দিয়ে local service চালু করবে, তারপর Edge বা Chrome-এর আলাদা app window খুলবে। আলাদা browser tab চাইলে NEXUS-Web.cmd চাপো। Edge/Chrome না পাওয়া গেলে default browser চেষ্টা করা হবে।
  3. ছোট voice orb-এর Settings দেখো। প্রায় 320×380 px-এর compact UI আগে খুলবে। Settings → Prepare/retry-তে setup progress থাকে; বড় dashboard খুলতে হবে না। প্রথমবার প্রয়োজনীয় AI engine ও models background-এ প্রস্তুত হবে। কতটা ডাউনলোড হয়েছে এবং কোনো error হয়েছে কি না এখানে দেখা যাবে।
  4. মডেল প্রস্তুত হলে ব্যবহার শুরু করো। Orb-এর Mic চাপো অথবা Text input-এ বাংলা/English/Banglish লিখো। প্রথম microphone permission-এ Allow দাও; এটি Windows/browser-এর প্রয়োজনীয় device permission।
  5. Desktop shortcut বানাও। Create-Desktop-Shortcuts.cmd চাপলে NEXUS AI ও NEXUS Web shortcut হবে। প্রতিবার সেই shortcut ক্লিক করলেই একই ডেটা নিয়ে খুলবে।

Executable-টি Windows x64-এর জন্য তৈরি। এটি আলাদা browser engine বা পূর্ণ native WinForms interface নয়; PC app mode-এ একই local web UI-কে Edge/Chrome app window-তে দেখায়।

২. কোন ফাইল কী করবে?

ফাইল / folderকাজ
NEXUS.exeমূল এক-ক্লিক PC app launcher।
NEXUS-Start.cmdমূল launcher-এর বিকল্প; app mode চালায়।
NEXUS-Web.cmdএকই assistant default browser-এ খোলে। এটি public Internet hosting নয়।
Stop-NEXUS.cmdনিজের local assistant-এর backend বন্ধ করে। মেমোরি বা completed checkpoints মুছে না।
Retry-Setup.cmdচলমান UI খোলে এবং প্রয়োজন হলে first-run setup আবার চেষ্টা করে।
Open-Without-Downloads.cmdনতুন সেশন চালানোর সময় automatic model download বাদ দেয়। আগে ডাউনলোড করা model এবং চালু engine service থাকলে ব্যবহার করা যাবে; না থাকলে offline tools/UI থাকবে। ইতিমধ্যে setup চললে এটি download cancel করে না।
Create-Desktop-Shortcuts.cmdDesktop-এ দুটি shortcut তৈরি করে। folder সরালে নতুন location থেকে আবার shortcut বানাতে হবে।
Open-Diagnostics.cmdlauncher.log ও Ollama log-এর folder খোলে। সমস্যার সঠিক error এখানে পাওয়া যাবে।
START-HERE.htmlএই সম্পূর্ণ বাংলা গাইড; browser-এ offline পড়া যায়।
runtime/pythonWindows x64 Python 3.13.16, standard library ও ২৮টি dependency bundle। এটি আলাদা Python installation-এর উপর নির্ভর করে না।
nexus / nexus/webBackend source, HTML/CSS/JS interface, voice controller, migrations ও Bengali font।
workspaceAI-এর অনুমোদিত কাজ ও project-এর folder। তোমার গুরুত্বপূর্ণ project আলাদা backup রাখো।
docs / tests / scriptsবিস্তারিত নকশা, সীমাবদ্ধতা, পরীক্ষার ফল, development ও Windows acceptance runners।
third-party-sourcesBundled speech/media component-এর source archives ও build/source notices।

৩. কী দেওয়া আছে, কী প্রথমবার নামবে?

এই প্যাকেজেই আছে: সম্পূর্ণ application source, actual Windows launcher executable, private Python runtime, Windows-compatible speech dependencies, UI assets, বাংলা font, tests ও বাংলা guide। pip-এর “Multiple top-level packages” সমস্যাও explicit package discovery দিয়ে ঠিক করা হয়েছে। নতুন portable launch-এ pip চালানোই লাগে না।

প্রথমবার নামবে: official Ollama Windows engine, Gemma3 4B language model, Whisper large-v3 বাংলা speech recognition, small fallback এবং Piper বাংলা/English voice models। বড় model weights এই ZIP-এর মধ্যে embed করা নেই। কয়েক GB download ও প্রস্তুতির সময় লাগতে পারে; Internet-এর গতি অনুযায়ী সময় বদলাবে।

অ্যাপ খোলা আর AI model প্রস্তুত হওয়া আলাদা ধাপ। মূল UI এবং local tools model নামার আগেই খোলে। কথোপকথন ও neural voice-এর জন্য model প্রস্তুত হওয়া প্রয়োজন। প্রথমবার model download-এর সময় Internet বন্ধ হলে Retry setup চাপো।

Data drive-এ প্রথম setup-এর জন্য অন্তত 20 GB free space পরীক্ষা করা হয়। official engine-এর আকার বা temporary extraction-এর জন্য আরও জায়গা লাগতে পারে। System/user-data drive আলাদা হলে LocalAppData drive-এ জায়গা রাখো। পরেরবার model cache ব্যবহার করবে; সবকিছু প্রতি launch-এ নতুন করে নামাবে না। Ollama engine-এর incomplete ZIP আবার শুরু থেকে নামতে পারে; verified installed engine ও model cache সংরক্ষিত থাকে।

Default local model-এ API key নেই। Models প্রস্তুত হয়ে গেলে local conversation/voice Internet ছাড়াও চলতে পারে। Web search, online source retrieval বা নতুন model download-এর জন্য Internet লাগবে।

Native dependency পরীক্ষা

Speech-এর actual imports পরীক্ষা হবে। DLL error হলে signed official Microsoft Visual C++ x64 runtime-এর standard repair setup খুলতে পারে; UAC permission বা restart লাগতে পারে। Checksum/signature ব্যর্থ হলে execute করবে না। এই repair এখানে Windows-এ চালানো হয়নি।

৪. স্বাভাবিক বাংলা voice companion

Orb-এর Settings-এ greeting চালু রেখে Mic চাপলে “বস, কী হয়েছে? বলো, শুনছি।” বলে শুরু করতে পারে। তুমি কথা বলার পর একটু বিরতি দিলে transcription হবে; উত্তর বলে শেষ করে আবার শোনার পালা শুরু হবে। তোমার ও NEXUS-এর কথাগুলো UI-তে দেখা যাবে।

  • সম্বোধন: বস, ভাই, অথবা নিজের নাম।
  • ভঙ্গি: বন্ধুর মতো, শান্ত বা পেশাদার।
  • ভাষা: বাংলা, English অথবা Auto; বাংলা neural voice-এ ১৬টি speaker choice আছে।
  • গতি: নিজের speaking speed বেছে নাও; default silence window কথার শেষে বিরতি শনাক্ত করে।
  • Stop: mic, audio ও বর্তমান voice turn বন্ধ করে। Mute: spoken reply বন্ধ রাখে; text reply দেখা যায়। Continuous mode-এ কথার শেষে উত্তর দেয়; Push-to-talk mode-এ আবার Mic চাপলে turn পাঠায়।
  • শোনার সময় “ভয়েস বন্ধ করো” বলেও বন্ধ করা যায়। Assistant নিজের উত্তর বলার সময় mic শোনে না; full-duplex barge-in নেই।

Headphone ব্যবহার করলে echo কমতে পারে। Bengali transcription সব কথা নিখুঁতভাবে বুঝবে না—পরীক্ষায় ভুল পাওয়া গেছে। UI-তে transcript দেখো; অস্পষ্ট input-এর কিছু ধরন ধরা পড়লে NEXUS আবার বলতে চাইবে। ভুল transcript হলে Text input দিয়ে ঠিক কথাটি পাঠাও; optional full workspace-এর manual input-এও transcript edit করা যায়। কাজের permission কেবল কথায় দেওয়া যায় না; exact action-এর approval UI-তে দিতে হয়।

৫. কাজ, পড়াশোনা, কোড ও মেমোরি

Default orb commands: “এখন কয়টা বাজে”, “what time is it”, “time bolo”, “open YouTube”, “গুগল খোলো”, “calculator kholo”, “open notepad”। Clock actual local time পড়ে। Fixed websites browser-এ open request পাঠায়; app launch exact confirmation চায়। অস্পষ্ট command হলে নাম জানতে চাইবে। Delete/message/system change voice mapping নেই; arbitrary shell চালায় না। কাজের ফল না দেখে completion বলে না।

Conversation mode: প্রশ্ন, পড়াশোনা, ব্যাখ্যা ও planning। যেমন “সিরিজ আর parallel circuit বাংলায় উদাহরণসহ বুঝিয়ে বলো।” উত্তর model তৈরি করে; গুরুত্বপূর্ণ factual বা গণনার উত্তর যাচাই করো।

Task / use tools: workspace-এর ফাইল, অনুমোদিত code runner, project environment, memory বা registered tools ব্যবহার করে কাজ। যেমন “workspace-এ একটা Python todo project বানাও এবং গুরুত্বপূর্ণ behavior যাচাই করো।” বদলাতে হবে এমন action-এর নির্দিষ্ট arguments দেখিয়ে approval চাইবে।

Task center: queued, active, completed বা failed কাজ, plan ও step result দেখা যায়। Completed checkpoints SQLite-এ থাকে। Crash-এর পর known-safe কাজ resume হতে পারে; আংশিক side effect হয়েছে কি না নিশ্চিত না হলে আগে review লাগে। সব রকম কাজের exact mid-instruction অবস্থান ফিরিয়ে আনার নিশ্চয়তা নেই।

Memory: দরকারি তথ্য save, search এবং forget করা যায়। Voice session-এর conversation history session অনুযায়ী আলাদা হয়। Privacy settings-এ memory access বন্ধ করা যায়। এটা unrestricted self-training বা AGI নয়; online information retrieval ও saved preferences অনুমোদিত পদ্ধতিতে কাজে লাগানো হয়।

Custom environment: Environment tool দিয়ে নিজের workspace-এর মধ্যে project template তৈরি করা যায়। Game lab-এ নিজের sandbox maze আছে। Genshin Impact/Roblox-এর autonomous play এই build-এ connected বা verified নয়।

৬. অ্যাপ বন্ধ, background কাজ ও ২৪/৭ ব্যবহার

Native app window প্রথমবার শনাক্ত হওয়ার পরে Windows × দিয়ে বন্ধ করলে backend-ও স্বাভাবিকভাবে বন্ধ হয়। Orb-এর × অথবা Stop-NEXUS.cmd দিয়েও বন্ধ করো। Browser tab বন্ধ করা backend shutdown signal নয়; browser mode-এ Stop ব্যবহার করো। আবার খুললে completed tasks ও memory থাকে। Background কাজ ধরে রাখতে window minimize করে রাখো।

Windows sleep, shutdown বা power failure হলে চলতে পারবে না। Long-running কাজের জন্য PC awake থাকা দরকার। এই প্যাকেজ নিজে থেকে Windows startup service, Task Scheduler entry বা system power settings বদলায় না। Supervisor abnormal exit-এর পরে সীমিত সংখ্যায় restart করে; uncertain actions review করতে হয়।

Test-Reliability.cmd একটি আসল ২৪ ঘণ্টার backend test চালায়। ছোট smoke test থেকে ২৪/৭ reliability প্রমাণ হয় না। এই runner microphone, model load বা native UI-এর পূর্ণ দিনের endurance মাপে না। বর্তমান release-এর পূর্ণ ২৪ ঘণ্টার soak ও native Windows device test সম্পন্ন হয়নি।

৭. পুরোনো NEXUS 0.3 থেকে আপডেট

  1. পুরোনো NEXUS session Stop assistant দিয়ে বন্ধ করো। পুরোনো launcher থাকলে সেই session-এর Ctrl+C ব্যবহার করো।
  2. নতুন ZIP একটি নতুন folder-এ Extract করো। পুরোনো .runtime, .venv বা ভাঙা installer copy করার প্রয়োজন নেই।
  3. পুরোনো workspace-এর নিজের কাজ নতুন workspace-এ copy করো, অথবা source-mode configuration-এ পুরোনো workspace ব্যবহার করো।
  4. আগের official launcher-এর %LOCALAPPDATA%\NEXUS memory ও downloaded models নতুন version ব্যবহার করে। পুরোনো source-mode project-এর data/runtime আলাদা হলে নিজের backup ও manual migration প্রয়োজন।
  5. নতুন NEXUS.exe খুলে Settings, Memory ও Projects দেখে নাও। পুরোনো shortcut নতুন folder-এ point না করলে আবার shortcut বানাও।

নতুন source-mode package install চাইলে python -m pip install -e ".[desktop,perception,voice]" কাজ করার জন্য packaging fix আছে। কিন্তু bundled portable version ব্যবহার করতে এই command লাগবে না।

৮. সমস্যায় কী করবে?

লক্ষণসমাধান
ক্লিক করে কিছু খুলছে নাপুরো ZIP Extract হয়েছে কি না দেখো। runtime/python/pythonw.exe থাকতে হবে। Open-Diagnostics.cmd খুলে launcher.log দেখো।
UI খুলেছে, AI উত্তর নেইSettings → Prepare/retry setup-এর progress দেখো। Model প্রস্তুত না হলে conversation কাজ করবে না; download error হলে Retry চাপো।
Multiple top-level packagesএটি পুরোনো source package-এর error। এই version-এ explicit nexus package discovery আছে; portable mode-এ pip install লাগে না।
Microphone deniedBrowser ও Windows microphone permission পরীক্ষা করো। তারপর orb-এর Mic দিয়ে retry করো অথবা Text input ব্যবহার করো।
