## What changed and why

The recovered source, launcher, package discovery, dependencies and existing logs were inspected. The earlier flat-layout setuptools error is resolved by explicit package discovery; the clean build confirms that. The bundled portable launcher opens the compact orb before model setup and reuses dependencies/session, so a normal launch does not reinstall packages.

New fixes: missing socksio transport wheel/extra; complete 128-bin v3 preprocessor/tokenizer/vocabulary readiness; setup rechecks all requested models instead of returning a false ready status; English persona no longer contains a Bengali instruction; true role pairs and adjacent-reference compatibility for models that require alternating turns; bounded recent context and 320 voice tokens; once-per-session completed greeting; generation-safe Stop/capture/output callbacks; fixed Piper subprocess working directory and bounded ONNX thread defaults; serialized profile/preset saves; actual requested/fallback voice indication; validated production STT/task/TTS binding and valid WAV checks before saving a device result. Raw microphone WAV is not persisted.

Real Bengali model arithmetic failures led to a deterministic bounded calculator. The default is Gemma3 4B and full Whisper large-v3, CPU-only (6 model threads, 4096 context, Whisper int8/4 threads, Piper 2 intra-op threads). This selection is a practical local configuration, not a target i5-13400/16 GB benchmark or promise of AGI performance. Combined pipeline self peak RSS was 3904 MiB on this Linux run; it excludes the separate model server and is not total application RAM. Backend namespace RSS failures are explicitly reported rather than guessed.

## Remaining target-PC acceptance

Actual Windows fresh extraction/first model setup, NEXUS.exe/native DLL imports and signed Microsoft repair/UAC, native window controls, real microphone/speaker, physical permission/autoplay/echo behavior, human Bengali/Banglish accuracy, i5 latency/load and full 86400 seconds have not been performed here. Test-Native-Windows exercises executable/native controls only; the built-in device check stores completed jobs plus separately labeled human accuracy/audibility observations, including the possibility of virtual devices. Test-Voice-24h exercises actual recorded-fixture ASR/model/neural-WAV load on the running app, without a physical microphone or audible-speaker claim. Interrupted or failed runs cannot produce a full-day pass. PC must remain awake.

The aggregate suite failure must remain visible. Read transcript/retry or use text fallback when recognition is wrong; an upgraded installed model can be selected in Full workspace Settings. Model replies can still be inaccurate. No commercial-game adapter or autonomous model-weight self-training is included.
